# Game-Verse
GameVerse – A cross-platform gaming platform bringing together board, puzzle, racing, fighting, adventure, and arcade games. Play solo, challenge friends, compete online, and climb global leaderboards.

## Status

Phase 0 (foundation). No application code yet. Stack: C# end to end (.NET 10 backend, Unity 6 client, shared `GameVerse.Rules` library), see [ADR-0001](docs/architecture/adr-0001-core-technology-stack.md).
